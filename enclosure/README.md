# enclosure/ — 3D 打印结构件

QLOCKTWO 风格英文字钟的外壳。**v3 面向 192×192 LED 灯板 PCB**
（`hardware/pcba.step`，尺寸/元件高度见 [`../docs/pcba-heights.md`](../docs/pcba-heights.md)）。

> v1/v2（`scad/wordclock.scad`）是**灯条**方案（pitch 16.58 行槽 + 过条缺口），
> 已被 PCB 方案取代，保留仅作参考。

## 分层（后 → 前）

```
Z=-19.0 ┌──────────── 背板 2.4 (shell)
        │  电子仓 15      ← ESP32-C5-DevKitC-1 + 走线
Z=-1.6  ├──────────── PCB 1.6（正面朝前：灯珠 + 控制区元件）
```

## 件与打印

| 件 | 尺寸 | 料（PLA） | 打印方向 | 备注 |
|---|---|---|---|---|
| `shell` | 200×200×33.5 | ≈170 cm³ / **211 g** | 背板朝下，壁朝上 | 一体出托边/定位柱/卡座/开孔，免支撑 |
| `grid` | 193×193×14 | ≈99 cm³ / **123 g** | 前面朝下 | 110 格通孔 + 4 角点腔，免支撑 |
| `faceplate` | 204.8×204.8 | ≈105 cm³ / **130 g** | **正面朝下**贴 PEI 纹理板 | 字母镂空 + 侧裙 + 8 个卡扣 |
| `diffuser` | 192×192×0.5 | — | **不打印** | 硫酸纸 ×2 或 1mm PC 光扩散板，按模板裁 |
| `snap_test` | 90mm 段 | ≈5 cm³ / 6 g | 平放 | **先打这个**调卡扣松紧 |

合计 PLA ≈ **464 g**（含支撑/余量请备 550g）。

## 卡扣结构（免螺丝）

- 前面板侧裙（内面留 0.25mm 滑动间隙）包住外壳外壁；
- 侧裙内面 **8 个楔形卡扣**（每边 2 个），嵌进外壳外壁一周的 **0.6mm 深卡扣槽**（Z 7.5…9.5），过盈 0.1mm；
- 卡扣上下 45° 斜面 → 前面板**正面朝下打印时免支撑**，装拆靠侧裙弹性；
- PCB **不打螺丝**：落在带 42° 斜底面的环形托边上，由 4 根 Ø3 定位柱穿过 4×M3 孔定位，
  格栅 + 扩散层 + 前面板压紧。拆前面板即可整机维护。

## ESP32-C5-DevKitC-1 与 USB-C 供电母口

- **DevKit 竖装**（长边竖直、USB 朝下）在电子仓左侧：占位 X 12…37.4，Y -1…52.6，贴背板内面凹槽内；
  四角压扣（顶部 2 + 侧面 2，避开天线区）压住板边；板厚 1.6、排针可朝向 PCB 一侧。
- **DevKit 的两个 USB-C**（UART / 原生 USB）从**底壁**开出，位置按 Espressif 尺寸图
  （DevKit 局部 x=5.5 / 19.9，距板边 0mm）→ 实机可免拆机烧录/看日志。
- **USB-C 供电母口**在底壁 X≈155 处开 9.5×5mm（参数 `pwr_cx/pwr_w/pwr_h`），
  内侧贴装面板式 Type-C 母座，飞线到灯板 **J2（5V IN）**。
  换不同母座时只改这三个参数重导出即可。
- 底壁三个开孔都是 3mm 壁上的通孔（顶边约 10mm 跨桥），打印时留意该处桥接。

## 装配顺序

1. 打印 `shell` / `grid` / `faceplate`（顺序建议先 `faceplate` 试卡扣松紧）。
2. 裁扩散片 192×192。
3. 灯板放进 `shell`：对准 4 根定位柱落下，落在环形托边上。
4. 装上 DevKit（压扣），接 J1↔DevKit 4pin、J2↔Type-C 母座，TestPoint 走线。
5. `grid` 扣在灯板上（字母格对准灯珠；角点腔对准 4 角 LED）。
6. 扩散片放上格栅顶面。
7. `faceplate` 对位压下，听到 8 声「咔」即锁紧。

## 校验

`part="check"` 会把灯板（灯珠/角点/控制区元件/安装孔）+ 格栅 + 面板叠在一起渲染，
用于核对开孔对齐（`stl/pcb_v3/preview/check_*.png`）：

```bash
cd enclosure/scad
openscad -o /tmp/check.png --camera=600,-500,500,96,96,0 --viewall --projection=o \
         -D 'part="check"' wordclock_pcb.scad
```

## 打印建议

- 材料：黑色哑光 PLA / PETG（**格栅与面板必须深色**，否则透光/串光）。
- `faceplate` 正面朝下贴纹理板；`shell` 背板朝下；`grid` 前面朝下。
- 200mm 平板类件翘边：brim + 首层降速 + 封闭腔体。
- **建议顺序**：先打 `snap_test`（6g，5 分钟）确认卡扣松紧 → 再打 `faceplate` 验证
  侧裙/字母 → 最后 `shell` + `grid`。配得太紧改小 `snap_d`，太松改大（每次 0.1mm）。
