# enclosure/ — 3D 打印结构件

QLOCKTWO 风格英文字钟的外壳。

**当前版本 = v4**：适配 **192×202 灯板（V-CUT 工艺边不掰断）**、**前面板 + 格栅一体件**、
**扩散层改为打印膜**（AMS 双料）。整机 **2 个打印件**（+ 1 个可选 USB 盖板），
无裁膜、无螺丝、无胶（母插板点一点热熔胶）。

> v3（`scad/wordclock_pcb.scad`，192×192 三件套 + 裁膜）保留作历史/回退参考；
> v1/v2（`scad/wordclock.scad`）是灯条方案，已废弃。

## 打印膜（AMS，全程 2 次换料）

三个 body **Z 向堆叠、互不重叠**，所以每层只属于一种料：

1. `front_black`（黑）：面板 1.2 + 格网 14
2. `front_white`（白）：1.2 整幅膜，夹在两者之间

> ⚠️ **每个 part 的挖洞必须写在自己的几何里**。切片时 `front_black` / `front_white`
> 是两个独立 part，黑色件上的字母洞**不会**减掉白色件的材料——`front_white()` 内部
> 用 `difference()` 自己切掉了字母窗的前 `cut_into_m`，这一点改动时别丢。

切片软件里：把 `front_black.stl` 与 `front_white.stl` **合并成一个 object 的 2 个 part**，
分别指定料槽即可（Bambu Studio：选中两者 → 右键「合并」→ 逐 part 选料槽）。
**不要**把膜按字母切成 114 片——那会变成每层上百次换刀。

要点：

- **同族材料**：黑 PLA + 白/半透 PLA（或整体都 PETG）。**禁止 PLA/PETG 混用**，界面会脱层。
- 白的厚度就是亮度/雾化的旋钮。**字母窗内可见厚度 = `m_t − cut_into_m` = 0.8**
  （太小→过亮有热点，太大→偏暗）。要调整时改 `m_t`，保持 `cut_into_m ≥ 0.4`。
- **桥接**：膜层要在 110 个字母窗上架桥（最大 11.6mm），这是全件最需要留意的地方。
  Bambu 默认桥接参数一般能过；试片若塌陷，把 `max_w` 从 11.6 降到 9.5 再导。
- 膜外廓 200（比腔体 204 小 4）→ 从面板与壳体的缝隙看不到白边。
- 件的**外侧面永远是黑的**：膜比面板小 7.4mm，不会出现"边缘白线"。

## 换料 / 擦料塔（250×250 热床）

`front_black` 是 214.8×214.8，而 P2S 热床 250×250：**居中摆只剩 17.6mm/边**，
而擦料塔默认宽 35 + 裙边，必然冲突。按下面三步处理即可：

1. **件不要居中**：把它摆到热床一个角（如 X/Y 都靠 0），这样两条边各剩 **35.2mm**，
   自动放置的擦料塔就有位置（塔宽 20 / 裙边 0 一定放得下）。
2. **不要为了省料把冲刷体积设 0**：黑→白的冲刷是在**废料槽**完成的，不进零件；
   设 0 反而让残余黑料被挤到零件上。保留默认（黑→白约 100–280，取 200 更稳）。
3. **擦料塔可以直接关**：多材料 → 擦料塔 → 取消「启用」。换料仍在废料槽冲刷，
   塔只用于稳压力/擦嘴；关掉后首层会有一个极小起挤点（可开「回抽时擦嘴」）。
   某些版本不允许关闭时，退而求其次：塔宽 **15**、裙边 **0**（214.8+15=229.8 ≤ 250 ✓）。

### 结构保险：换料"染色"点已经被设计掉了

即便冲刷不足，本模型也不会把染色露在脸上：

| 换料 | 发生位置（打印层） | 染色落在哪 | 是否可见 |
|---|---|---|---|
| 黑 → 白 | 面板 1.2mm 结束处 | 膜的**第 1–2 层** | **字母窗内被切掉**（窗深 = 面板 1.2 + 进膜 0.4），窗外夹在两层黑之间 |
| 白 → 黑 | 膜结束处（14.0） | 格网的**纸层面**（贴膜那面） | 不可见；侧壁痕迹要从字母窗斜看，实际看不出 |

关键参数 `cut_into_m = 0.4`（≥2 层）：字母/角点窗再切进白膜 0.4mm，
**窗内可见的扩散面 = 换料后第 3 层**，把染色层直接切掉。
所以你能看到的白面永远是"洗干净之后"挤出的料 → 与 `coupon` 的光学完全一致
（coupon 也用了同一套切深，建议重新打一片确认）。

## 装配顺序

1. 焊线（台面操作）：灯板**背面 3mm 尾针**上焊 26AWG（见下「接线」）。
2. 灯板落进 `body`：对准 4 根 Ø3 销落下，坐在 Ø7 台肩上。
3. 装 DevKit（平躺在右墙侧卡座里，器件朝 +Z）、母插板（竖立在背板凹坑上，点热熔胶）、
   把线卡进 2 个过线梳；插上 `usb_cover`（可选）。
4. `front_black`+`front_white` 对位压下，听到 8 声「咔」。
5. 贴后脚垫（自备硅胶脚垫，见「摆放」）。

拆解：从底边 2 个撬槽插薄片，整块光腔抬起（一体件刚度好，可反复拆装）。

## 接线（P1：焊背面尾针）

- J1/J2 排针已焊在正面，**孔已被焊锡填满**，所以从背面焊「3mm 尾针」是最省事的路子
  （OSP 工艺不影响：这是在已有焊点上加锡，不是往处女焊盘上焊）。
- 网络：`J2` 2×5V + 2×GND（电源输入）；`J1` 5V/GND/DIN（到 DevKit）+ 可选 `+5V_DEV`。
- 正面因此只剩排针座 8mm 高，14mm 格腔余量充足；线全部走在电子仓里，**不需要在壳上开走线槽**。
- 焊完用扎带/热熔胶把线束固定在仓内，别让力落在针脚上。

电气注意（写进装机规范）：

1. 正常使用（母插 → J2 → 灯板 → J1 → DevKit）**必须短接 JP1**（默认断开）。
2. **烧录时先拔掉 5V 适配器**，避免 USB 与适配器 5V 并联反灌。
3. 供电线/母插按 **≥3A** 选；满白 6.8A 超出 USB-C 能力，实际按 1/4–1/3 亮度使用。
4. 母插侧建议用 **90° 弯头 USB-C 线**（贴墙走、且不撬那块 1.6mm 小转接板）。

## 接口分布

| 面 | 内容 |
|---|---|
| 正面 / 四边框 / 底边 | 无（底边是竖放接触面，整条 3mm 干净壁） |
| **背面** | USB-C 供电母插（低、居中 X≈96 / Y≈30，开孔 9.6×5.2）+ 2 个过线梳 |
| **右侧墙** | DevKit 两个 USB-C 共用一个开口（10×5 ×2）+ 34×16×1.5 凹槽 + 盖板 |

## 摆放

竖立使用：底边倒角 + **自备硅胶脚垫**（背面下沿贴两个），使背面离墙 ~15–18mm，
给 90° 电源插头留出空间，同时明显改善 33mm 进深站立的稳定性。

## 已知风险 / 待决

1. **打印膜亮度**：可见厚度 0.8mm，白 PLA 透光约 20–35%；已用 `coupon` 验证通过。
2. **横向导光**：整幅连续白膜理论上存在邻格串光（实测通常可忽略），coupon 点一颗灯即可确认。
3. **字母窗桥接**：见「打印膜」一节，试片不合格就降 `max_w`。
4. **天线**：DevKit 的模块天线距灯板背面 5.6mm（中间无金属），一般够用；
   若 RSSI 差，可在卡座下垫 5mm 抬高或把器件面翻转朝背板。
5. **背板厚度 2.4 / 母插处剩 1.4**：够用但不富余；若换更长的母插板需重算。
6. 母插板出线轴必须沿 **14mm** 短边（当前模型按此假设）；若实物是 20mm 方向出线，
   背面方案要重新布（告知即可改参数）。
