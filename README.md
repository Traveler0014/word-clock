# word-clock-enclosure

3D 打印结构件（OpenSCAD 参数化源码）。

## 关键参数（与硬件绑定，改动前先对齐）

| 参数 | 值 | 来源 |
|---|---|---|
| 灯距 pitch | 16.67mm | WS2812B 60灯/米，**先用卡尺实测灯条实际间距再定稿** |
| 字面 | 11 列 × 10 行 → 183.4 × 166.7mm | 字母阵 |
| 整机外框 | ~215 × 200mm | 250³ 热床可一体打印 |
| 格栅壁厚 / 高度 | 1.2mm / 15mm | 0.4 喷嘴 3 层壁；高度防串光 |
| LED 槽宽 | 灯条 PCB 宽 +0.3mm | 常见 10mm 板宽 → 10.3mm |

## 分层结构（后 → 前）

1. **背板**：LED 行定位槽 + 走线孔 + 电子仓（ESP32、电源座）
2. **格栅**：每字一格防串光，黑色哑光
3. **扩散层**：硫酸纸 / 1mm PC 光扩散板 / 0.2mm 白色透光 PLA 薄板
4. **前面板**：字母镂空（见下）

## 前面板字母方案（三选一）

- **A. 镂空 + 衬扩散层**：字母完全切透。A/O/D/P/Q/R 等含孤岛字母必须用 **stencil 字体**（带桥接），最省事，推荐 MVP 用
- **B. 车贴**：淘宝定制镂空字车贴贴亚克力，效果最好，跳过 3D 打印字体问题
- **C. AMS 双色**：黑面板 + 字母区 0.6mm 白色凹陷透光，无需 stencil，但废料多、时间长

## 打印建议

- 材料：黑色哑光 PLA 或 PETG（格栅必须深色防透光）；前面板黑
- 前面板**正面朝下**贴 PEI 纹理板，获得细腻表面
- 格栅无顶底面、3 层壁即可，省料省时
- 先打 2×2 格小样验证：灯条嵌入松紧、格栅高度是否漏光、16.67 间距是否对齐

## 文件

- `scad/wordclock.scad`：参数化格栅 / 背板 / 面板框。改 `part` 变量分件导出 STL
