# 灯板 PCB 方案评估

> 背景：10 行 WS2812B 灯条方案的行间飞线（5V/GND/DIN 三根 × 9 处）+ 首尾二次注入，
> 焊点/接触电阻/线径/发热都难控。改用**单块定制 PCB**把 114 颗灯、蛇形数据链、
> 电源分配、电平转换（可选主控）全部做在板上。
> 本文只做方案评估与参数决策，尚未动工；决策项见文末「开放问题」。

## TL;DR

- **可行，且是正确方向**：PCB 把 9 处飞线消成 0，电源从"线"变成"铺铜平面"，接触/发热问题从根上消除。
- **尺寸必须重新定 pitch**：角点光腔 + 11 列累积决定宽度。若"成品 200×200"是硬约束，
  建议 **pitch 15.0mm、PCB ≈192×192、外壳 200×200**（字母阵 165×150）。
- **主控有两种接法**：
  - 方案 A（低风险、先做）：保留现有 ESP32-C5-DevKitC，灯板只做灯 + 电平转换，
    用 **1 根 4pin 排线**（5V/GND/DATA）连接，固件零改动。
  - 方案 B（终态、推荐）：把 **ESP32-C5-WROOM-1** 直接贴到灯板上，USB-C 一线上电+烧录+日志，
    彻底无飞线。需要新增电源树/复位/天线设计，固件只改 sdkconfig 控制台。
- 建议路径：**A 验证灯板 → 结构/光学确认 → B 集成版 v2**。

## 1. 现状确认（2026-08）

| 项 | 状态 |
|---|---|
| 固件 | Phase A-MVP 实机点亮：RMT 自检 → WiFi → SNTP(UTC+8) → 每分钟整帧刷新 ✅ |
| 逻辑层 | `wordclock-core` 114 颗（110 字母 + 4 角点），9 个宿主机测试通过，no_std |
| 数据链 | 蛇形，行 0 从左到右，奇数行反向；**链尾 index 109 在左下角**（row9/col0） |
| 角点 | index 110~113，固件只按「点亮前 n 颗」使用（n = minute % 5） |
| 引脚 | RMT 数据 = GPIO4；光敏预留 GPIO1(ADC1_CH0) |
| 结构 | OpenSCAD v2 全套（格栅/背板/前面板/角点腔/校验规），按 16.58 pitch、外框 210.4×193.8 |
| 电源 | 5V/4A + 74AHCT125 + 1000µF；实测最大同时点亮 ≤28 颗，限亮 1/4 后 <0.5A |

灯带方案的痛点（本评估要解决的）：
1. 每行 11 颗剪段 → 9 处 × 3 根手工焊接（27 个焊点 + 剪口偏移）；
2. 5V/GND 靠细线串联，行末压降 → 颜色不均/发热；
3. 热熔胶固定，长期振动/温升后接触电阻漂移；
4. 角点 4 颗要单独立式接线。

## 2. 为什么 PCB 能解决

| 维度 | 灯带飞线 | 灯板 PCB |
|---|---|---|
| 行间连接 | 27 焊点手工焊 | 板上走线，0 飞线 |
| 电源 | 细线串联、末端压降 | 5V/GND 铺铜平面，整板等电位 |
| 数据链 | 行间跳线 | 板上蛇形走线，长度可控 |
| 角点 | 立式飞线 | 同板 4 颗，随链尾 |
| 一致性 | 剪口/间距靠目视 | 光刻对位，pitch 精确 |
| 可维护 | 难拆 | 整板可换 |
| 成本 | 低（已有灯条） | 打样+SMT 一次性投入 |

## 3. 尺寸 / pitch 决策（★最关键）

定义：`p` = 灯中心距，11 列 × 10 行；`m` = 字面四周留边；
**板宽 = 11p + 2m，板高 = 10p + 2m**。角点光腔放在四角留边里，
要求 `m/2 ≥ 腔半径 + 1mm`（腔居中时）。

> 结论：**角点是宽度瓶颈**。要 ≤200 宽，11p + 2m ≤ 200；腔要做到 ~φ11~13 就只能缩 pitch。

| 方案 | pitch | 留边 m | 字母阵 | 板尺寸 | 角点腔 | 说明 |
|---|---|---|---|---|---|---|
| A 沿用现间距 | 16.58 | 8.8 | 182.4×165.8 | **200.0×183.4** | φ6（小点） | 保 pitch，但角点必须缩到 φ6/窗 φ4；外壳 ~206×190 |
| B | 15.5 | 14.25 | 170.5×155.0 | **199.0×183.5** | φ12 | 角点舒适；外壳 ~207×191（若外壳也要 ≤200 则不行） |
| **C 推荐** | **15.0** | **13.5** | **165.0×150.0** | **192.0×177.0** | **φ11** | **PCB 192 + 4mm 壁 = 成品 200×185**；方形面板可用 192×192（上下留边 21）→ 成品 **200×200** |
| D 更小 | 14.5 | 14.0 | 159.5×145.0 | 187.5×173.0 | φ12 | 外壳 ~195×181，余量更足 |

**推荐基线（成品 200×200 正方形）**：
- PCB 192×192×1.6mm，2 层，1oz（可选 2oz）
- pitch **15.0mm**；字母阵 165×150 **居中**（左右 13.5 / 上下 21）
- 4 角分钟点在面板四角，**距边 7mm**，光腔 φ11，前面板窗 φ5
- 114 颗 WS2812B 5050（蛇形 110 + 角点 4）

> 若"200×200"指的是 **PCB 本身**（外壳可略大），可用方案 B（pitch 15.5，角点更舒展）。

## 4. 电学设计

### 4.1 LED 选型

| 型号 | 尺寸 | 优点 | 缺点 |
|---|---|---|---|
| **WS2812B 5050**（推荐） | 5×5mm | 成熟、亮、便宜、货源多 | 功耗大、需 100nF×N |
| WS2812B-2020 | 2×2mm | 小、省电、可更小 pitch | 亮度低、焊接难 |
| SK6812 RGBW 5050 | 5×5mm | 独立 W 通道，暖白更纯、发光效率高 | 协议 4 字节，固件需改 |

MVP 先用 **WS2812B 5050**，与现有固件/颜色一致（`COLOR = 255,190,110`）。SK6812 RGBW
作为 Phase A-Full 选项（改 `leddrv.rs` 为 4 字节/像素）。

每颗 LED 配 **100nF 0402/0603 去耦**（WorldSemi 推荐 1 颗/灯；预算紧张时最少 1 颗/2~4 灯）。
另加板级 **1000µF 电解 + 22µF + 100nF** 在电源入口。

### 4.2 电流与铺铜

- 实测最大同时点亮 ≤28 颗；限亮 1/4 后总电流 **<0.5A**（含静态）。
- 理论全白 114 × ~50–60mA ≈ **5.7–6.8A**（软件不会达到，但设计留 3A 余量）。
- **2 层 1oz + 铺铜平面**足够：底层做 **5V 平面**，顶层做 **GND 铺铜** + 数据走线；
  每颗 LED 的 VDD 用 2~3 个过孔就近接到 5V 平面，VSS 接顶层 GND。平面载流能力远超需求。
- 如要全白跑满，用 **2oz 铜** 或限制亮度。导热上铺铜也能帮助 5050 散热。
- 密封腔体内散热差 → 固件亮度保持 1/4，必要时加通风孔或金属背板（见 §6）。

### 4.3 数据链走线

- 严格按 `wordclock-core::xy_to_index` 的蛇形：行 0 从左到右，奇数行反向。
- **链尾 = index 109 = 左下角字母灯**（row9/col0），紧接着才是 4 颗角点。
- 角点在 PCB 上按**周长环**布线最省路径（从链尾出发）：
  `109(左下) → 110 左下点 → 111 右下点 → 112 右上点 → 113 左上点`。
- **注意**：现有 `docs/wiring.md` 写的是 `110 左上 / 111 右上 / 112 左下 / 113 右下`，
  与物理链尾方向不符。由于固件只看「前 n 颗」，物理顺序不影响功能，但**建议统一为周长环并更新文档**；
  若必须`minute=1 → 左上`，在 `Frame::dots()` 加一张映射表即可（1 行改动）。
- 数据线宽 0.2mm 即可；每颗 LED 的 DOUT→下一颗 DIN 就近走线，可加 **33~100Ω 串联**（可选）。

### 4.4 电平转换（必备）

ESP32-C5 是 **3.3V** 逻辑，WS2812B VIH = 0.7×VDD ≈ **3.5V**，3.3V 直驱在 5V 供电下不可靠。
- **74AHCT1G125**（SOT-23-5，单通道）或 **74AHCT125**（SOIC-14），**用 5V 供电**，3.3V 输入兼容（VIH≈2.0V）。
- 输出串 **33~100Ω** 到首颗 DIN；芯片旁 **100nF** 去耦；未用输入接地。
- 备选：74LVC1T45（双电源）或 74HCT245。**不要用 BSS138 方案**（800kHz 边沿太软）。

### 4.5 电源入口

```
DC/USB-C 5V ──[PTC 自恢复保险 + TVS + 反接保护]── 1000µF ─┬─ 5V 平面 → LEDs
                                                          └─ (集成版) LDO/Buck 3.3V → C5
```
- 反接保护：P-MOSFET 或串联肖特基；TVS 选 5.5~6V（SMBJ5.0A）。
- 输入连接器：DC-005（5.5×2.1 桶座）或 **USB-C**（5.1k×2 CC 下拉；需 5V/3A 电源）。
- 测试点：`5V / GND / DATA_IN（移位前）/ DATA_AFTER（移位后）`，方便示波器/排障。

### 4.6 连接器（方案 A / 调试）

- **4pin JST-XH 2.54**（或 JST-PH 2.0）：`1=5V, 2=GND, 3=DATA, 4=GND/备用`。
- 预留一个 **数据旁路跳线**：可断开板上控制、由外部注入 DATA（做对比测试或备援）。
- 预留 **DOUT 焊盘**：可外接第二块板/测试。

## 5. 与 ESP32-C5 的连接

### 方案 A：保留现有 DevKitC（推荐先做）

```
ESP32-C5-DevKitC-1                    灯板 PCB
  GPIO4 ────────────────► [33Ω] ──► 74AHCT1G125(5V) ──[33Ω]──► 首颗 DIN
  GND   ────────────────► GND ─────────────────────┐
  5V    ◄─────────────── 5V （或开发期各自供电，必须共地）│
                                                1000µF + 平面
```
- **1 根 4pin 排线**，无行间飞线。固件**零改动**（仍 GPIO4、仍 114 颗）。
- 开发期：DevKitC 走 USB 供电时，**断开灯板向 DevKitC 供 5V 的那根**（或加跳线/二极管），避免双电源互灌。
- 量产/组装：统一由灯板 5V 输入供电给 DevKitC。

### 方案 B：ESP32-C5-WROOM-1 上板（终态推荐）

已核对 ESP32-C5-WROOM-1 数据手册（v1.3）与 C5 芯片手册（v1.5），关键事实：

- 模组 **18.0×27.5×3.3mm**，29 焊盘（含 EPAD），3V3 供电 **3.0~3.6V**，外部供电需 ≥**0.6A**；
  5GHz TX 峰值 **403mA**，2.4GHz **313mA** → 3.3V 稳压选 **≥0.8A**。
- 原生 **USB-Serial-JTAG** 在 `IO13 = USB_D-`、`IO14 = USB_D+`，**无需 CH9102F**；USB-C 一线搞定
  供电+烧录+日志（需把 sdkconfig 控制台从 UART0 改成 USB-Serial-JTAG）。
- **strapping 脚：GPIO2/3/7/25/26/27/28**。其中 IO27/IO28 默认内部上拉（=1），
  **SPI Boot 要求 IO28=1**；`Joint Download Boot 0` = IO28 拉低。→ **BOOT 按键接 IO28**。
- **EN**：10kΩ 上拉 3.3V + 1µF 到 GND（RC 延时，手册推荐 R=10k/C=1µF），配 RESET 按键。
- 未用/慎用：IO15~18、IO20~22（SPI flash/PSRAM）；IO11/12（UART0）；IO13/14（USB）。
- **天线**：PCB 天线对铺铜极敏感。整板是 LED + 5V/GND 平面，会严重失谐/吸收 2.4/5GHz。
  → **强烈建议用 `ESP32-C5-WROOM-1U`（u.FL 外置天线）**，或严格 keep-out（天线区各层禁铜 + 边缘外伸）。

**建议引脚分配（方案 B）**：

| 功能 | 引脚 | 说明 |
|---|---|---|
| LED DATA (RMT) | **IO4** (MTCK) | 与现固件一致；用了它就不用 pad-JTAG（用 USB-JTAG 调试） |
| 光敏 ADC | **IO1** (ADC1_CH0) | 与现有 `wiring.md` 一致；分压 GL5528 + 10k |
| I2C (DS3231 等) | **SDA IO23 / SCL IO24** | P2 脚、非 strapping；**不要用 IO2/IO3**（strapping + LP_I2C） |
| USB | **IO13 / IO14** | 90Ω 差分，直连 USB-C |
| UART0 调试 | IO11 / IO12 | 仅留测试点，可不用 |
| BOOT | **IO28** | 按键拉低 + 10k 上拉 |
| RESET | **EN** | 按键 + 10k 上拉 + 1µF |
| 预留 | IO0/IO5/IO6/IO8/IO9/IO10/IO25 | 避开 IO26/27/28 |

**电源树（方案 B）**：

```
USB-C 5V ─┬─[PTC+TVS]─ 5V 平面 ──┬─ 114×WS2812B
          │  (CC 5.1k×2)         ├─ 1000µF + 22µF + 100nF
          │                      └─ LDO(AMS1117-3.3)/Buck ─ 3.3V ─ ESP32-C5-WROOM-1
          └─ USB D+/D- ──────────── IO14 / IO13
```
- 3.3V 若用 AMS1117：压差 1.7V × 0.4A ≈ 0.68W，靠铺铜散热尚可；更优用同步 Buck（MP2315 等）。
- 模组底部 **EPAD 建议焊到 GND**（热性能）。
- USB 口放板边，外壳开孔对齐。

## 6. 结构配合（enclosure 改动）

灯板让背板大幅简化，但**格栅（防串光）仍必须保留**：

1. **删除**：背板 10 条 LED 行槽、行端走线孔、纵墙过条缺口、四角过线孔。
2. **背板 → PCB 载体**：四角/四边中点做定位柱 + M3 沉头孔；或**直接用 PCB 当背板**
   （省一件、减薄），由格栅立柱压紧 PCB。
3. **格栅**：墙底直接坐在 PCB 平面（墙在灯与灯之间，不与灯珠干涉）；高度按
   `LED 顶面(≈PCB 1.6 + LED 1.6) → 扩散层` 取 12~15mm。角点腔与板上角点对齐。
4. **电子仓**：方案 B 时 USB-C/按键开孔；建议把主控区放在板下缘留边（14~21mm）或做外伸凸台。
5. 总厚 ≈ `1.6(PCB) + 1.6(LED) + 12~15(格栅) + 0.3~1(扩散) + 2.4(面板)` ≈ **18~21mm**。
6. PCB 平整度好，扩散层贴合更均匀；但 LED 比原"沉槽灯带"高约 1.5mm，格栅高度相应加。
7. 面板/格栅尺寸随新 pitch 重算，字母阵两处（scad 与 `lib.rs`）保持同步。

## 8. 打样 / 装配 / 预算（量级估计，以实际报价为准）

- **PCB**：2 层 192×192、1.6mm、黑油、ENIG，5 片 ≈ ¥80–160；4 层（若做完整平面）≈ ¥200–400。
- **元件**：WS2812B 5050 ×114 ≈ ¥30–60；100nF ×114 ≈ ¥3；C5-WROOM-1U ≈ ¥25–45；
  稳压/USB-C/连接器/电容 ≈ ¥20。合计 ≈ ¥80–130。
- **SMT 打样**：约 300+ 元件（LED + 去耦 + 模组），贴片费可能 **¥200–500**；
  手焊（热台/风枪）可省，但 114 颗 5050 费时且有虚焊风险。
- 单块样板总投入 ≈ **¥400–800**（含 SMT），批量后显著下降。
- 建议先打 **1 块纯灯板（方案 A）**验证，再做集成版。

## 9. 风险 / 开放问题（需你拍板）

1. **"200×200"是 PCB 尺寸还是成品（含外壳）尺寸？** → 直接决定 pitch（15.0 还是 15.5）。
2. 是否**第一版就上 C5 模组**（方案 B），还是先做纯灯板（方案 A）？建议 A→B。
3. 角点大小取舍：保 16.58 就得把角点缩到 φ6（方案 A），否则缩 pitch。
4. LED 封装：5050 / 2020 / SK6812 RGBW。
5. 天线：PCB 天线 vs **WROOM-1U 外置天线**（推荐）。
6. 去耦密度：100nF/灯（稳）vs /2~4 灯（省）。
7. 散热与密封：亮度上限、是否开通风/加金属背板。
8. 电源接口：桶座 vs USB-C；是否要 PD 协商（5V 固定即可）。
9. 灯珠一致性：同批次、同 bin（色温/亮度）。

## 10. 建议下一步

4. 验证光学/结构（串光、扩散、角点）后再做**方案 B 集成版**。
