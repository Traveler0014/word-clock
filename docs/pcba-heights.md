# 灯板 PCBA 元件高度实测（hardware/pcba.step）

> 结论先行：**最高的正面元件是 C117（1000µF 电解）11.5mm，其次是 J1/J2 排针 8.5mm。**
> 结构件按「格栅净高 14mm」设计，给 C117 留 2.5mm 余量。
>
> 复核方式：用 OpenCASCADE（XCAF）解析 `hardware/pcba.step`，逐个元件实例求
> 世界坐标包围盒；插件（排针/电解）的 3D 体在 STEP 里是占位方块，高度改用
> LCSC 规格书数据。脚本见本文末。

## 1. 板子本体

| 项 | 值 | 说明 |
|---|---|---|
| PCB 实际轮廓 | **191.85 × 191.85 × 1.6 mm**（设计值 192×192） | STEP 中间那块实体 |
| STEP 里总轮廓 | 191.85 × 201.85 mm | 上下各多一条 **~4.85mm 工艺边**（V-CUT，分 3 块实体，缝隙 0.15mm） |
| 板子坐标 | STEP 中 192 板体 x∈[0.075,191.925]，y∈[5.075,196.925] | 结构件只认 192×192，工艺边掰掉 |

> ⚠️ 不要用 STEP 的外包络（202）当板宽，否则结构件会长 10mm。

## 2. 元件高度（正面 / Z 从灯板表面起算）

| 位号 | 型号 | 封装 | 高度 | 来源 |
|---|---|---|---|---|
| **C117** | NCC APSG160ETD102MJB5S（LCSC **C525818**，1000µF/16V D10×11.5） | 插件 D10 P5.0 | **11.5 mm** | LCSC「Height – Seated (Max) = 11.5mm」 |
| **J1 / J2** | HDGC HDGCPH-PZ01-04（LCSC **C19190970**，单排 1×4） | 插件 P2.54 | **8.54 mm** = 绝缘座 2.54 + 插针 6.0 | LCSC 属性 + HDGC 图纸（L11.6/3.0） |
| C116 | Samsung CL32A226KAJNNNE（22µF） | 1210 | 2.52 mm | STEP 实测 |
| D1–D114 | WS2812B-V5/W 5050 | SMD5050-4P | 1.61 mm（本体 1.6） | STEP 实测 |
| U1 | MDD 74AHCT1G125GV | SOT-23-5 | 1.26 mm | STEP 实测 |
| C115 | 0603 100nF | 0603 | 0.80 mm | STEP 实测 |
| R1 | 0603 33Ω | 0603 | 0.45 mm | STEP 实测 |
| C1–C114 | 0402 100nF | 0402 | 0.50 mm | STEP 实测 |

**J1/J2 与 C117 的 STEP 占位方块**：EasyEDA 只导出了焊盘（0.76×0.76×0.76），
没有插件本体的 3D 模型（见 `step` 里这三个实例的包围盒），**所以高度必须查规格书**。

> 选料注意：BOM 里的 1000µF 备选 **C10750（D10×17mm）高 17mm，塞不进 14mm 格栅**，
> 除非把格栅加到 ≥18mm 或在该处开天窗。当前选用的 C525818（11.5mm）没问题。

## 3. 结构件对应（enclosure/scad/wordclock_pcb.scad）

| 参数 | 值 | 取值理由 |
|---|---|---|
| `grid_h` | **14.0** | ≥ C117 11.5 + 1mm 余量；同时是匀光距离 |
| `grid_front_t` | 1.5 | 前端遮光面，盖住控制区（Z 12.5…14），底面离 C117 顶 1.0mm |
| `bay` | 15.0 | 后面放 DevKit + 排线 |
| 装机总厚 | **≈35.9 mm** | 背板 2.4 + 电子仓 15 + PCB 1.6 + 格栅 14 + 扩散 0.5 + 面板 2.4 |

## 4. J1/J2 选型（已修正）

- 焊盘：`PinHeader_1x04_P2.54mm_Vertical`，drill 里 J1/J2 是**同一列 y 步距 2.54** → 单排 1×4。
- ~~C492419（XFCN PZ254V-12-4P）~~ 是**双排 2×2**，插不进。
- ✅ **实际改用 LCSC `C19190970` = HDGC `HDGCPH-PZ01-04`**：单排 1×4，P2.54，
  金镀，绝缘座 2.54 + 插针 6.0 + 尾针 3.0（总长 11.6）→ **板面高 8.54mm**。
- 注：该件规格书要求 PCB 孔 Ø0.85±0.05（引脚 0.64 方），本板沿用 KiCad 标准 **Ø1.0**，
  波峰焊可填满，无影响。

## 5. 复现脚本

```bash
# 需要 OpenCASCADE python 绑定
uv venv /tmp/steptool --python 3.11
uv pip install --python /tmp/steptool/bin/python cadquery-ocp
/tmp/steptool/bin/python hardware/tools/inspect_step.py hardware/pcba.step
```

脚本对每个元件实例（含装配变换）求世界坐标包围盒并打印；
`Board` 那块的 3 个实体分别对应 工艺边 / PCB / 工艺边。
