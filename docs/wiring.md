```
                ┌──────────────┐
  5V/4A ────────┤ +        GND ├──────── GND ──────────────┐
   │            └──────────────┘                           │
   │   1000µF                                              │
   ├──||──┬── 灯条 5V (首端)                               │
   │      └── 灯条 5V (尾端, 二次注入)                     │
   │                                                       │
   │            ┌──────────────┐                           │
   │            │ ESP32-C5     │                           │
   └───────────►│ 5V(VIN)      │  (开发期: USB 供电, 但必须与灯条共地)

                │ GPIO4 ──470Ω─┼── 74AHCT125(1A→1Y) ──► 灯条 DIN

                └──────────────┘
                     74AHCT125: VCC=5V, GND 共地, OE 接地
```

## 灯链布局（蛇形，114 颗）

```
行0:  → → → … →   (11 颗, 索引 0-10)
行1:  ← ← ← … ←   (11-21, 反向)
行2:  → → → … →   (22-32)
…
行9:  ← ← ← … ←   (99-109)
角点:  110(左上) 111(右上) 112(左下) 113(右下)   ← 接在数据链末尾
```

- 行间焊接 5V / GND / DOUT→DIN 三根短线
- 奇数行物理反向，软件已在 `xy_to_index()` 处理
- GPIO 选的是 GPIO4；避开 strapping 引脚（详见 C5 datasheet）
- 74AHCT125 务必用 5V 供电（才是有效电平转换），未用通道输入接地

## 开发验证阶段接线（2026-08 实测，4 颗灯样本）

全尺寸结构前的最小验证配置：

```
ESP32-C5-DevKitC            WS2812B ×4（灯条）
  GND ─────────────────────► GND   （必须共地；灯条由独立 USB 5V 供电）
  GPIO4 ──[330Ω]───────────► DIN   （首颗；后续 DO→DIN 链式）
  （开发板 USB 供电，5V 引脚不接灯条）
```

实测结论：
- 4 颗峰值 ~240mA，独立 5V 供电绰绰有余；共地后 3.3V 数据电平直驱可靠
- 自检为整帧刷新（全链同色 R→G→B），4 颗同步变色 = 链路/级联/供电正常
- 冷态接线（两边先断电再接 GND）可避免电源电位差火花；绝不可连接两侧 5V
- 114 颗全链上电平转换（74AHCT125）与尾端供电二次注入前，先用 2×2 小样验证

## 首次点亮检查单

1. 万用表确认 5V / GND 无短路
2. 只接 ESP32，跑自检看日志（不亮=数据方向/电平问题）
3. 全链 RGB 自检：末端暗=压降，补尾端供电；颜色错=GRB 顺序
4. 上字库映射测试（逐行扫），确认蛇形方向与实际焊接一致
